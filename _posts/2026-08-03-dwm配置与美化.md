**dwm-beautiful 说明**：含 vanitygaps/systray/statuscmd/scratchpad/swallow/selfrestart/xresources 等补丁，配置在 `config.h`（参考 `config.def.h` 差异），依赖脚本需从作者 [dotfiles](https://github.com/saloniamatteo/dotfiles) 的 `scripts/.local/bin` 获取，`set-fan` 需要 ThinkPad + `thinkpad_acpi` 调风扇权限。

**st font**：`JetBrainsMonoNerdFont:pixelsize=14:antialias=true:autohint=true`（config.h `font`），另有 `font2` NotoColorEmoji。注意 `/usr/local/bin/st` 与 `~/bin/st` 二进制不完全一致，安装时以 `make && doas make install` 为准。

### ~/.xinitrc（WM 切换入口，dwm/i3/JWM 通用）

> 注意：**不推荐用 `startx ~/.xinitrc dwm` 传参方式**——WM 作为 X 客户端保持前台时，X 服务器会额外开一个终端显示日志。直接手写 `exec <wm>` 即可，切换 WM 时手动改这一行。

```sh
#!/bin/sh

export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
export XMODIFIERS=@im=fcitx
export SDL_IM_MODULE=fcitx

export LANG=en_US.UTF-8
export LANGUAGE=en_US:en

eval $(dbus-launch --sh-syntax)

[ -f ~/.dwm/autostart.sh ] && ~/.dwm/autostart.sh &

exec dwm
```

dwm 分支写法：`.xinitrc` 中 `exec dwm` 前需执行 `[ -f ~/.dwm/autostart.sh ] && ~/.dwm/autostart.sh &`，autostart.sh 内容见下节。

### 配套脚本

- `~/suckless/dwm-beautiful/dwm-color <颜色HEX|预设> [--install]`：修改 config.h 中 bar 文字/选中背景/聚焦边框 3 处颜色并重编译。预设：`nord-green/cyan/blue/orange/yellow/purple`、`onedark-green/blue/orange/purple`、`gruvbox-green/cyan`，也支持任意 `#RRGGBB`。当前为 Nord 绿 `#A3BE8C`。
- `~/.config/scripts/screenlock`：内容 `exec slock`，dwm `Super+l` 调用（config.h scripts[3]）。

### ~/.dwm/autostart.sh

由 `.xinitrc` 在 `exec dwm` 前调用：

```sh
#!/bin/sh
# dwm autostart script

# Load X resources
xrdb -merge ~/.Xresources 2>/dev/null

# Start status bar script
~/.config/dwm/dwm-status.sh &

# Start sxhkd
sxhkd &

# Start fcitx5
fcitx5 &

# Polybar disabled - using dwm native bar
# ~/.config/polybar/launch.sh &

# Set wallpaper
xwallpaper --zoom ~/Pictures/wallpaper.jpg &
```

### dwm-status.sh（状态栏）

`~/.config/dwm/dwm-status.sh`（5 秒更新，直接写 dwm stext，不依赖 dwmblocks）：

```bash
#!/bin/bash
# dwm status bar script - adapted from i3blocks
# Updates every 5 seconds

STATUS_BAR() {
    # Volume
    VOLUME=$(pactl get-sink-volume @DEFAULT_SINK@ 2>/dev/null | grep -oP '\d+%' | head -1 | tr -d '%')
    MUTE=$(pactl get-sink-mute @DEFAULT_SINK@ 2>/dev/null | grep -oP 'yes|no')
    if [ "$MUTE" = "yes" ]; then
        VOL_STR="Mute"
    elif [ -n "$VOLUME" ]; then
        VOL_STR="Vol: ${VOLUME}%"
    else
        VOL_STR="Vol: N/A"
    fi

    # Network
    IFACE=$(ip route 2>/dev/null | awk '/default/ {print $5}' | head -1)
    if [ -n "$IFACE" ]; then
        IP=$(ip -4 addr show "$IFACE" 2>/dev/null | grep -oP 'inet \K[\d.]+')
        ESSID=$(nmcli -t -f active,ssid dev wifi 2>/dev/null | awk -F: '$1=="yes"{print $2}')
        if [ -n "$ESSID" ]; then
            NET_STR="${ESSID} ${IP}"
        else
            NET_STR="${IP}"
        fi
    else
        NET_STR="NoNet"
    fi

    # Memory
    read -r TOTAL USED FREE <<< "$(free -h 2>/dev/null | awk '/Mem:/{print $2, $3, $7}')"
    MEM_STR="Mem: ${USED} / ${TOTAL}"

    # Weather (cache for 30 min)
    CACHE_FILE="/tmp/.dwm_weather_cache"
    CACHE_TIME="/tmp/.dwm_weather_cache_time"
    NOW=$(date +%s)
    if [ -f "$CACHE_FILE" ] && [ -f "$CACHE_TIME" ]; then
        CACHED_AT=$(cat "$CACHE_TIME")
        DIFF=$((NOW - CACHED_AT))
        if [ "$DIFF" -lt 1800 ]; then
            WEATHER=$(cat "$CACHE_FILE")
        fi
    fi
    if [ -z "$WEATHER" ]; then
        WEATHER=$(curl -s --max-time 5 "wttr.in/Beijing?format=%C+%t+%h" 2>/dev/null)
        [ -n "$WEATHER" ] && echo "$WEATHER" > "$CACHE_FILE" && echo "$NOW" > "$CACHE_TIME"
    fi
    [ -z "$WEATHER" ] && WEATHER="N/A"

    # Date & time (with weekday)
    WEEKDAY=$(date +%w)
    case $WEEKDAY in
        0) WEEK_STR="日" ;; 1) WEEK_STR="一" ;; 2) WEEK_STR="二" ;;
        3) WEEK_STR="三" ;; 4) WEEK_STR="四" ;; 5) WEEK_STR="五" ;; 6) WEEK_STR="六" ;;
    esac
    DATETIME="${WEEK_STR} | $(date "+%m-%d %H:%M")"

    echo "${VOL_STR} | ${NET_STR} | ${MEM_STR} | ${WEATHER} | ${DATETIME}"
}

# Update status bar every 5 seconds
while true; do
    xsetroot -name "$(STATUS_BAR)"
    sleep 5
done &
```

> 天气接口 `wttr.in/Beijing` 中的城市可按需替换；脚本自带 30 分钟缓存，避免高频请求。

### 注意事项

- dwmblocks 已弃用：config.h 中 `STATUSBAR ""`，媒体键已去掉 dwmblocks 刷新调用
- status2d 分色补丁与现有 patch 冲突，放弃；如需分色手动移植 `drawstatusbar` 函数（约 100 行）
- dwm 无空闲自动锁屏，需 xautolock 自行安装配置
- 显卡：Intel Sandy Bridge 核显（i915 + modesetting），Mesa 25.0.7；GL 3.3、VAAPI 硬件解码正常、Vulkan 仅 llvmpipe（Gen6 无硬件 Vulkan）
- 完整快捷键参考 `~/data/wm-keybindings.md`
