### 组件与安装

| 组件 | 来源 | 配置 |
|---|---|---|
| i3 | 系统包 | `~/.config/i3/config` |
| i3blocks | 系统包 | `~/.config/i3blocks/` |

```bash
apt install i3
```

启动入口见 [dwm 配置与美化](2026-08-03-dwm-配置与美化.md) 中的 `~/.xinitrc`——切到 `exec i3` 即可，i3 自身无 autostart 需求（在配置内 exec 启动程序）。

### i3blocks 配置

**`~/.config/i3blocks/config`**：
```
# i3blocks configuration file

separator_block_width=15

[weather]
command=~/.config/i3blocks/weather
interval=1800

[volume]
command=~/.config/i3blocks/volume
interval=2

[wireless]
command=~/.config/i3blocks/wireless
interval=60

[memory]
command=~/.config/i3blocks/memory
interval=10

[weekday]
command=~/.config/i3blocks/weekday
interval=300

[tztime]
command=~/.config/i3blocks/tztime
interval=60
```

### 各 block 脚本

**`~/.config/i3blocks/weather`**：
```sh
#!/bin/sh
# i3blocks weather block - wttr.in
WEATHER=$(curl -s "wttr.in/Beijing?format=%t+%C" 2>/dev/null)
if [ -n "$WEATHER" ]; then
    echo "$WEATHER"
    echo "$WEATHER"
    echo "#89b4fa"
else
    echo "--"
    echo "--"
    echo "#666666"
fi
```

**`~/.config/i3blocks/volume`**：
```bash
#!/bin/bash

VOLUME=$(pactl get-sink-volume @DEFAULT_SINK@ | grep -oP '\d+%' | head -1 | tr -d '%')
MUTE=$(pactl get-sink-mute @DEFAULT_SINK@ | grep -oP 'yes|no')

if [ "$MUTE" = "yes" ]; then
    ICON="静"
    COLOR="#666666"
elif [ "$VOLUME" -ge 70 ]; then
    ICON="高"
    COLOR="#aaffaa"
elif [ "$VOLUME" -ge 30 ]; then
    ICON="中"
    COLOR="#ffffaa"
else
    ICON="低"
    COLOR="#ffaaaa"
fi

echo "$ICON ${VOLUME}%"
echo "$ICON ${VOLUME}%"
echo "$COLOR"
```

**`~/.config/i3blocks/wireless`**：
```bash
#!/bin/bash

IFACE=$(ip route | awk '/default/ {print $5}' | head -1)
if [ -z "$IFACE" ]; then
    echo "无网络"
    echo "无网络"
    echo "#ff6666"
    exit 0
fi

IP=$(ip -4 addr show "$IFACE" | grep -oP 'inet \K[\d.]+')
ESSID=$(nmcli -t -f active,ssid dev wifi 2>/dev/null | awk -F: '$1=="yes"{print $2}')

if [ -n "$ESSID" ]; then
    echo "${ESSID} ${IP}"
    echo "${ESSID} ${IP}"
else
    echo "${IP}"
    echo "${IP}"
fi
echo "#aaffaa"
```

**`~/.config/i3blocks/memory`**：
```bash
#!/bin/bash

read -r total used free <<< "$(free -h | awk '/Mem:/{print $2, $3, $7}')"
echo "M: $used / $total"
echo "M: $used / $total"
```

**`~/.config/i3blocks/weekday`**：
```bash
#!/bin/bash

DAY=$(date +%u)
case $DAY in
    1) TEXT="一" ;;
    2) TEXT="二" ;;
    3) TEXT="三" ;;
    4) TEXT="四" ;;
    5) TEXT="五" ;;
    6) TEXT="六" ;;
    7) TEXT="日" ;;
esac

echo "$TEXT"
echo "$TEXT"
```

**`~/.config/i3blocks/tztime`**：
```bash
#!/bin/bash

DATETIME=$(date "+%m-%d %H:%M")
echo "$DATETIME"
echo "$DATETIME"
```

> 天气接口 `wttr.in/Beijing` 中的城市可按需替换。
