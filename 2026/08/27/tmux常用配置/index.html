为什么用 tmux

极简窗口管理器（dwm/i3）+ st/zt 极简终端只追求轻量，但终端本身没有标签页。tmux 以 ~3MB 内存补齐了标签页能力，同时还带来会话保持：SSH 断开、终端关闭，会话里的程序照样后台运行，重连即恢复。

配置要点：

  • 前缀键：C-z 比默认 C-b 更顺手，且与 emacs 风格不冲突
  • 分屏：| 左右 / - 上下，比默认 % / " 直观；hjkl 切窗格，H/J/K/L 调大小
  • 真彩色：terminal-overrides + terminal-features 让 helix/neovim 颜色不丢失
  • 复制模式：vi 键位，y 复制到系统剪贴板（Wayland 用 wl-copy，X11 退回 xclip）
  • 状态栏：居中的 Gruvbox 配色，活动窗格高亮，左侧显示会话名，右侧显示当前路径和时间
  • 窗格边框：顶部显示窗格编号 + 当前命令

结语

tmux 以极小的资源开销补齐了极简终端的标签页与分屏能力，还自带会话保持，配合 st/zt 是极简工作流的理想组合。想换口味可试 Rust 实现的 zellij，功能更现代化，但 tmux 胜在生态成熟、配置稳定。
