dwm-beautiful 说明：含 vanitygaps/systray/statuscmd/scratchpad/swallow/selfrestart/xresources 等补丁，配置在 config.h（参考 config.def.h 差异），依赖脚本需从作者 dotfiles 的 scripts/.local/bin 获取，set-fan 需要 ThinkPad + thinkpad_acpi 调风扇权限。

st font：JetBrainsMonoNerdFont:pixelsize=14:antialias=true:autohint=true（config.h font），另有 font2 NotoColorEmoji。注意 /usr/local/bin/st 与 ~/bin/st 二进制不完全一致，安装时以 make && doas make install 为准。

~/.xinitrc（WM 切换入口，dwm/i3/JWM 通用）

注意：不推荐用 startx ~/.xinitrc dwm 传参方式——WM 作为 X 客户端保持前台时，X 服务器会额外开一个终端显示日志。直接手写 exec <wm> 即可，切换 WM 时手动改这一行。

dwm 分支写法：.xinitrc 中 exec dwm 前需执行 [ -f ~/.dwm/autostart.sh ] && ~/.dwm/autostart.sh &，autostart.sh 内容见下节。

配套脚本

  • ~/suckless/dwm-beautiful/dwm-color <颜色HEX|预设> [--install]：修改 config.h 中 bar 文字/选中背景/聚焦边框 3 处颜色并重编译。预设：nord-green/cyan/blue/orange/yellow/purple、onedark-green/blue/orange/purple、gruvbox-green/cyan，也支持任意 #RRGGBB。当前为 Nord 绿 #A3BE8C。
  • ~/.config/scripts/screenlock：内容 exec slock，dwm Super+l 调用（config.h scripts[3]）。

注意事项

  • dwmblocks 已弃用：config.h 中 STATUSBAR ""，媒体键已去掉 dwmblocks 刷新调用
  • status2d 分色补丁与现有 patch 冲突，放弃；如需分色手动移植 drawstatusbar 函数（约 100 行）
  • dwm 无空闲自动锁屏，需 xautolock 自行安装配置
  • 显卡：Intel Sandy Bridge 核显（i915 + modesetting），Mesa 25.0.7；GL 3.3、VAAPI 硬件解码正常、Vulkan 仅 llvmpipe（Gen6 无硬件 Vulkan）
  • 完整快捷键参考 ~/data/wm-keybindings.md
